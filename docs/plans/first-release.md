# 首次发布计划

状态：待完成。范围：完成 GWM 首次发布所需的验证与人工决策，不新增产品能力。

本计划接续初始实现后的发布准备。四个实施阶段及当时的验证已移入 [初始实施归档](../archive/initial-implementation.md)。发布步骤和通用门槛以 [发布指南](../RELEASING.md) 为准，产品边界与行为分别以 [DESIGN](../DESIGN.md) 和 [SPEC](../SPEC.md) 为准。

## 待办

- [ ] 在 Linux 和 macOS 13+ 上验证最低与当前 Git/Go 组合。
- [ ] 确定首次发布版本号并完成人工发布决策。

最低要求为 Git 2.39、Go 1.26。已有本地验证和交叉构建记录不代替目标平台与最低版本组合的发布级验证。验证证据记录在对应发布 PR 或任务中，本计划只跟踪待办及结果引用。

## 验收

- 发布指南中的质量门槛、平台验证和制品检查均有对应证据。
- 维护者明确选择首次版本号、目标 commit 并决定发布；版本号不由本计划预设。
- 未完成待办前不创建并 push release tag。计划存在、开发工作或流水线已配置均不等于发布授权。

首次发布完成后，将有回顾价值的结果归档，并更新 [文档索引](../README.md#维护者入口)；通用规则继续维护在发布指南中。
